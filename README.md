# EHP On Cloud อบจ.น่าน Dashboard

สรุปผลการดูแลการใช้งานระบบ EHP On Cloud ของ รพ.สต. ที่ถ่ายโอน 106 แห่ง ตาม `constitution.md`

## ใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ไม่ต้องติดตั้งอะไร)
2. นำเข้าข้อมูลจาก Google Sheet การตอบกลับของฟอร์ม ด้วยวิธีใดก็ได้
   - ไฟล์ → ดาวน์โหลด → `.csv` แล้วกด “เลือกไฟล์ CSV” หรือลากไฟล์มาวาง
   - เลือกทั้งตาราง (รวมแถวหัวตาราง) ใน Sheet → คัดลอก → วางในช่องบนหน้า
3. ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น กด “ล้างข้อมูล” เพื่อลบ

เป็นเครื่องมือภายในทีม มีชื่อบุคคล ห้ามเผยแพร่ลิงก์สาธารณะ และห้าม commit ไฟล์ข้อมูลจริง

## โครงสร้าง

- `index.html` — หน้าเดียวครบ: `<script id="ehp-core">` คือ logic ทั้งหมด (อ่าน CSV/TSV, หาคอลัมน์ตามชื่อหัวตาราง, จับคู่หัวข้อ Checklist, คำนวณสรุป) ไม่แตะ DOM; สคริปต์ถัดไปคือ UI เท่านั้น
- `tests/core.test.mjs` — unit test ของ `ehp-core` (`npm test`, ต้องมี Node 20+)
- `tests/fixtures/` — หัวตารางจริงของฟอร์ม + ข้อมูลสมมติสำหรับทดสอบ (`node tests/fixtures/build-sample.mjs` เพื่อสร้างใหม่)

เมื่อแก้ Google Form ให้ทดสอบกับ CSV ล่าสุดก่อนใช้งาน (constitution: ขั้นตอนการพัฒนา ข้อ 2)
