# EHP On Cloud อบจ.น่าน Dashboard

สรุปผลการดูแลการใช้งานระบบ EHP On Cloud ของ รพ.สต. ที่ถ่ายโอน 106 แห่ง ตาม `constitution.md`

## ใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หน้าจะดึงข้อมูลจาก Google Sheet การตอบกลับของฟอร์มให้อัตโนมัติ
2. กด “โหลดข้อมูลล่าสุด” เพื่อดึงข้อมูลใหม่
3. กด “เปลี่ยนลิงก์” เพื่อใช้ Sheet อื่น (จำไว้ในเบราว์เซอร์เครื่องนั้น) หรือ “ใช้ลิงก์เริ่มต้น” เพื่อกลับไปใช้ลิงก์เดิม

Sheet ต้องแชร์แบบ “ทุกคนที่มีลิงก์ดูได้” หน้านี้จึงอ่านได้ — ลิงก์เริ่มต้นอยู่ที่ `DEFAULT_SHEET_URL` ใน `index.html`
เว็บ: https://nuchanarts.github.io/nanpao.ehp-data/ (สาธารณะ — มีชื่อบุคคล แชร์ลิงก์เฉพาะในทีม) · ห้าม commit ไฟล์ข้อมูลจริง

## โครงสร้าง

- `index.html` — หน้าเดียวครบ: `<script id="ehp-core">` คือ logic ทั้งหมด (แปลงลิงก์ Sheet, อ่าน CSV, หาคอลัมน์ตามชื่อหัวตาราง, จับคู่หัวข้อ Checklist, คำนวณสรุป) ไม่แตะ DOM; สคริปต์ถัดไปคือ UI เท่านั้น
- `tests/core.test.mjs` — unit test ของ `ehp-core` (`npm test`, ต้องมี Node 20+)
- `tests/fixtures/` — หัวตารางจริงของฟอร์ม + ข้อมูลสมมติสำหรับทดสอบ (`node tests/fixtures/build-sample.mjs` เพื่อสร้างใหม่)

เมื่อแก้ Google Form ให้ทดสอบกับ CSV ล่าสุดก่อนใช้งาน (constitution: ขั้นตอนการพัฒนา ข้อ 2)
