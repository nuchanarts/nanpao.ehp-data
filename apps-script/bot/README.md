# บอทแมวส้ม: ส่งสถานะไฟล์ใน Drive ให้ Dashboard

เมนู **ส่งออกข้อมูล** ของ Dashboard ทำรายงานราย รพ.สต. ได้ครบ 3 ส่วน:
ผลการแนะนำ (จากฟอร์ม), ประวัติการเข้าแนะนำ (จากฟอร์ม) และ **เอกสารใน Google Drive** (รายงานติดตั้ง BF1 BF2 AT1 AT2 และไฟล์ Cleansing C01 C02 C03)

Dashboard อ่าน Google Drive เองไม่ได้ บอทแมวส้มอ่าน Drive อยู่แล้วทุก 15 นาที
ไฟล์ `DriveStatus.gs` ให้บอทเขียนผลลงแท็บ **สถานะไฟล์ Drive** ใน Google Sheet ของฟอร์ม แล้ว Dashboard อ่านแท็บนั้น
ไม่ต้องใช้ token เพิ่ม

- เขียนแค่ "มี / ไม่มี" ของแต่ละไฟล์ ไม่เขียนชื่อไฟล์ ลิงก์ หรือเนื้อหาในไฟล์
- ถ้ายังไม่ติดตั้ง Dashboard ยังใช้งานได้ รายงานส่วนที่ 3 จะแสดงว่า "ไม่มีข้อมูล"

## ติดตั้ง (ประมาณ 5 นาที)

1. เปิด Apps Script ของบอท → ➕ ข้าง "ไฟล์" → สคริปต์ → ตั้งชื่อ `DriveStatus` → วางโค้ดจาก `DriveStatus.gs` → บันทึก
2. ใน `Code.gs` ฟังก์ชัน `checkDrive_` หาบรรทัด

   ```js
   refreshCleansing();   // อัปเดตสถานะไฟล์ Cleansing ไปพร้อมกัน
   ```

   แล้วเพิ่มบรรทัดนี้ต่อท้าย

   ```js
   try { writeDriveStatusSheet_(); } catch (err) { console.error('เขียนแท็บสถานะไฟล์ไม่ได้: ' + err); }
   ```

3. เลือกฟังก์ชัน `updateDriveStatusSheet` → เรียกใช้ → จะมีแท็บ **สถานะไฟล์ Drive** ใน Sheet
4. เปิด Dashboard → เมนู **ส่งออกข้อมูล** → กล่องด้านบนจะขึ้นว่า "สถานะไฟล์ใน Google Drive จากบอทแมวส้ม · ข้อมูล ณ …"

ไม่ต้องทำ "เวอร์ชันใหม่" ของการทำให้ใช้งานได้ เพราะ `checkDrive` ทำงานจากทริกเกอร์เวลา ไม่ได้ผ่าน Web app

## ข้อควรรู้

- ห้ามเปลี่ยนชื่อแท็บหรือหัวตาราง Dashboard หาคอลัมน์จากชื่อหัวตาราง
- ถ้าข้อมูลในแท็บเก่ากว่า 1 ชั่วโมง Dashboard จะเตือนว่าบอทอาจหยุดทำงาน ให้ดูทริกเกอร์ `checkDrive` ใน Apps Script
- ไฟล์ที่นับว่า "มี" ใช้กติกาเดียวกับบอท: ชื่อไฟล์ขึ้นต้นด้วย BF1 BF2 AT1 AT2 และชื่อไฟล์ Cleansing มี C01/Cleansing_Card, C02/Cleansing_Allergy, C03/Cleansing_Visit

# (ทางเลือก) รวมรูปรายงานการติดตั้งทั้งรอบเป็นไฟล์ใน Drive (`InstallPrint.gs`)

> ปกติไม่ต้องติดตั้ง: ใช้ปุ่ม **พิมพ์รูปรายงานการติดตั้ง** ในเมนู **ส่งออกข้อมูล** ของ Dashboard ได้เลย
> ติดตั้งส่วนนี้เมื่ออยากได้ไฟล์ Google Doc / PDF เก็บไว้ในโฟลเดอร์ของรอบด้วย

รวมรูป BF1 BF2 AT1 AT2 ของทุก รพ.สต. ในรอบเดียวเป็นเอกสารเดียว เปิดแล้วสั่งพิมพ์ได้ทันที

- หน้าแรกเป็นสารบัญ: ทุกแห่งในรอบ เรียงตามรายชื่อ รพ.สต. และบอกว่าไฟล์ครบ ขาดไฟล์ไหน หรือยังไม่มีโฟลเดอร์
- หน้าถัดไป 1 แห่งต่อหน้า: ชื่อ รพ.สต. อำเภอ วันเปิดใช้ ผู้รับผิดชอบ และรูป 4 รูปเรียง 2×2 (ชื่อไฟล์และเวลาอัปโหลดอยู่บนรูป)
- บันทึกไว้ในโฟลเดอร์ของรอบนั้น 2 ไฟล์: Google Doc (แก้ไขได้) และ PDF
- สั่งใหม่เมื่อไรก็ได้ ไฟล์รอบก่อนที่ชื่อเดียวกันจะย้ายไปถังขยะ (กู้คืนได้ 30 วัน)
- ไม่รวม รพ.สต.นำร่อง · ไฟล์ที่ไม่ใช่รูปภาพ (เช่น PDF) จะขึ้นข้อความให้พิมพ์แยก

## ติดตั้ง

1. Apps Script ของบอท → ➕ → สคริปต์ → ตั้งชื่อ `InstallPrint` → วางโค้ดจาก `InstallPrint.gs` → บันทึก
2. ถ้า `Code.gs` มีฟังก์ชัน `onOpen` อยู่แล้ว ให้ย้ายบรรทัดใน `onOpen` ของ `InstallPrint.gs` ไปรวมกัน (มี `onOpen` ได้ฟังก์ชันเดียว)
3. เลือกฟังก์ชัน `testInstallPrint` → เรียกใช้ → อนุญาตสิทธิ์ (ครั้งแรก Google จะขอสิทธิ์สร้าง Google Docs) → ดูลิงก์ในบันทึกการดำเนินการ
4. รีเฟรชหน้า Google Sheet จะมีเมนู **🐱 แมวส้ม**

## ใช้งาน

เปิด Google Sheet → เมนู **🐱 แมวส้ม → พิมพ์รวมรายงานการติดตั้ง รอบ N** → รอ 1–3 นาที → กด **เปิด PDF แล้วสั่งพิมพ์**

- ถ้ารอบไหนใช้เวลาเกิน 5 นาที เอกสารจะหยุดที่แห่งสุดท้ายที่ทำได้และแจ้งไว้ ให้สั่งใหม่อีกครั้ง
- ถ้าสร้าง PDF ไม่ได้ (ไฟล์ใหญ่เกิน) ให้เปิด Google Doc แล้วเลือก ไฟล์ → พิมพ์

# รวมไฟล์ Cleansing ทั้งรอบเป็น PDF เดียวใน Drive (`CleansingPrint.gs`)

ไฟล์ Cleansing มีข้อมูลผู้ป่วย (HN รายคน) Dashboard จึงไม่ดึงไฟล์มาแสดงเอง (constitution V)
บอทรวมเอกสารทั้งรอบเป็น PDF เดียวใน Google Drive แล้วปุ่ม **พิมพ์ รอบที่ N** ในเมนู **Cleansing** ของ Dashboard เปิดไฟล์นั้นได้ทันที

- หน้าแรกเป็นสารบัญ: ทุกแห่งในรอบ เรียงตามรายชื่อ รพ.สต. บอกว่าไฟล์ครบ ขาดไฟล์ไหน หรือยังไม่มีโฟลเดอร์ และอยู่หน้าไหน
- ต่อด้วยเอกสารของแต่ละแห่ง เรียง C01 → C02 → C03: PDF ทุกหน้า และรูป JPG/PNG 1 รูปต่อหน้า A4
- บันทึกเป็น `พิมพ์รวม Cleansing รอบ N.pdf` ในโฟลเดอร์ Cleansing ของรอบนั้น (คนที่เปิดได้ = คนที่เปิดไฟล์ต้นฉบับได้)
- ถ้าไฟล์ต้นฉบับรวมเกินราว 25 MB จะแบ่งเป็น `… ส่วนที่ 1.pdf`, `… ส่วนที่ 2.pdf` (Dashboard มีปุ่มแยกแต่ละส่วน)
- สร้างใหม่เองทุกชั่วโมงเมื่อมีไฟล์ใหม่ หรือสั่งเองเมื่อไรก็ได้ ไฟล์ครั้งก่อนจะย้ายไปถังขยะ (กู้คืนได้ 30 วัน)
- ไฟล์ชนิดอื่น (เช่น Google Sheet `…_CleansingData`) ไม่รวม แต่บอกไว้ในสารบัญ
- ชื่อไฟล์ต้องมี C01/C02/C03 หรือ Cleansing_Card/Cleansing_Allergy/Cleansing_Visit ไม่อย่างนั้นนับว่า "ขาด"
- มีเมนู **นำร่อง** แยก เพราะโฟลเดอร์ Cleansing มีโฟลเดอร์ "นำร่อง"
- บอทเขียนแท็บ **PDF Cleansing** (ID ไฟล์รวม จำนวนหน้า การแชร์ เวลาที่สร้าง) ให้ Dashboard อ่าน ห้ามเปลี่ยนชื่อแท็บหรือหัวตาราง

## ⚠️ ต้องทำก่อน: แชร์โฟลเดอร์ Cleansing เฉพาะทีม

ตอนนี้ (2026-10-14) โฟลเดอร์ "รายงาน Cleansing ข้อมูลแยกรอบ" เปิดแบบ **ทุกคนที่มีลิงก์** ใครมีลิงก์ก็เปิดเอกสารผู้ป่วยได้

1. Google Drive → คลิกขวาโฟลเดอร์ Cleansing → แชร์ → เพิ่มอีเมลคนในทีมทุกคน (ผู้มีสิทธิ์อ่าน)
2. "การเข้าถึงทั่วไป" → เปลี่ยนเป็น **จำกัด**

Dashboard จะไม่แสดงปุ่มเปิดไฟล์ PDF รวมที่ยังเปิดสาธารณะ (ขึ้นคำเตือนและเปิดโฟลเดอร์แทน) — บอทอัปเดตการแชร์ในแท็บทุกชั่วโมง

## ติดตั้ง

1. Apps Script ของบอท → ➕ → สคริปต์ → ตั้งชื่อ `CleansingPrint` → วางโค้ดจาก `CleansingPrint.gs` → บันทึก
2. ถ้าติดตั้ง `InstallPrint.gs` แล้ว ให้วาง `onOpen` ใหม่จาก `InstallPrint.gs` ทับของเดิม (มีบรรทัดเรียก `addCleansingMenu_`)
   ถ้ายังไม่ได้ติดตั้ง ให้เพิ่มฟังก์ชันนี้ (มี `onOpen` ได้ฟังก์ชันเดียวทั้งโปรเจกต์)

   ```js
   function onOpen() {
     const menu = SpreadsheetApp.getUi().createMenu('🐱 แมวส้ม');
     addCleansingMenu_(menu);
     menu.addToUi();
   }
   ```

3. เลือกฟังก์ชัน `testCleansingPrint` → เรียกใช้ → อนุญาตสิทธิ์ (ครั้งแรก Google จะขอสิทธิ์ Drive, Docs, Sheet และเชื่อมต่อภายนอก) → ดูลิงก์ใน "บันทึกการดำเนินการ" และแท็บ **PDF Cleansing** ใน Sheet
4. เลือกฟังก์ชัน `installCleansingPrintTrigger` → เรียกใช้ (ครั้งเดียว) → บอทจะสร้าง PDF รวมใหม่เองทุกชั่วโมง ครั้งละ 1 รอบ เฉพาะรอบที่มีไฟล์ใหม่กว่า PDF เดิม
5. รีเฟรชหน้า Google Sheet จะมีเมนู **🐱 แมวส้ม → พิมพ์รวม Cleansing รอบ N** (สั่งสร้างทันทีโดยไม่ต้องรอทริกเกอร์)

ต้องใช้ฟังก์ชันจาก `Code.gs` ของบอท: `readMaster_`, `isPilot_`, `codeOf`, `listFiles_`, `fmt_` (ตัวเดียวกับที่ `InstallPrint.gs` ใช้)

## ใช้งาน

- **จาก Dashboard:** เมนู **Cleansing** → การ์ด "พิมพ์เอกสาร Cleansing ทั้งรอบในครั้งเดียว" → กด **พิมพ์ รอบที่ N** → PDF เปิดใน Google Drive → กดพิมพ์
- **สร้างใหม่ทันที:** เปิด Google Sheet → เมนู **🐱 แมวส้ม → พิมพ์รวม Cleansing รอบ N** → รอ 1–5 นาที → กดลิงก์ PDF แล้วสั่งพิมพ์

- ถ้าใช้เวลาเกิน 5 นาที จะหยุดที่แห่งสุดท้ายที่ทำได้และแจ้งไว้ในสารบัญ ให้สั่งใหม่อีกครั้ง
- บอทโหลดตัวรวม PDF (pdf-lib 1.17.1) จาก cdnjs ทุกครั้งที่สั่ง ถ้าโหลดไม่ได้จะขึ้นข้อความ "ทำไม่สำเร็จ"
- รูปที่ถ่ายจากมือถืออาจกลับด้าน (pdf-lib ไม่อ่านค่าการหมุนในรูป) — ให้หมุนรูปให้ตรงก่อนอัปโหลด
- PDF มีข้อมูลผู้ป่วย อย่าแชร์ไฟล์หรือโฟลเดอร์ออกนอกทีม
